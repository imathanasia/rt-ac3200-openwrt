# Credentials baked into the image (v1.x)

| Where | User | Password | URL |
|---|---|---|---|
| SSH / LuCI (root) | `root` | `ac3200-admin` | `ssh root@192.168.1.200` / `https://192.168.1.200` |
| AdGuard Home | `admin` | `ac3200-admin` | `http://192.168.1.200:3000` |
| Wi-Fi (all three) | - | `ac3200-change-me-now` | WPA2; change in LuCI -> Network -> Wireless |

Change them immediately:
* root: `passwd` (SSH) or LuCI → System → Administration
* AdGuard: AdGuard Home → Settings → change the admin password

The root password is set by `/etc/uci-defaults/96-rootpass.sh` (SHA-512 crypt hash).
The AdGuard admin hash is a bcrypt hash inside `/etc/adguardhome/adguardhome.yaml`
(config was generated on the live unit, so the YAML schema matches the binary).

If you ever lock yourself out: hold **Reset** during power-up to get the ASUS
recovery mode reachable at `192.168.1.1` (see docs/flash-guide.md), or reset the unit with the button
(10 s) — the baked config is regenerated on first boot.
